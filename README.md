## QuickNotes System Design

# About the Project

QuickNotes is a simple notes app that allows users to load notes, create new notes, and delete notes from the screen.

I built this project to practise using HTML, CSS, and JavaScript. I also learned how to connect a web page to an API to get and send information.

# What the App Can Do

Load sample notes.

Create a note with a title and body.

Delete a note from the list.

Show messages when notes are loading or when something goes wrong.

Check that a note has a title before creating it.

# Tools I Used

HTML to build the page.

CSS to style the page.

JavaScript to make the buttons and form work.

JSONPlaceholder to practise getting, creating, and deleting notes.

# How to Use the App

Open index.html in your browser.

Click Load notes to display sample notes.

Enter a title and body to create your own note.

Click Delete to remove a note from the displayed list.

Note: This app uses a practice API, so created and deleted notes are not permanently saved on the server.

# Project Files

index.html – the main page of the app.

style.css – the styles and colours.

api.js – the code that loads, creates, and deletes notes.

docs/api-design.md – information about the API.

docs/data-model.md – information about how the data is organised.

docs/architecture.md – information about how the system works.

# What I Learned

How HTML, CSS, and JavaScript work together.

How to get information from an API.

How to create and delete notes using API requests.

How to show messages when an action succeeds or fails.

Why it is important to plan how an application works before building it.
